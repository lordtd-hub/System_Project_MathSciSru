# Manual screenshots

เก็บภาพประกอบคู่มือที่ถ่ายจาก QA จริงไว้ในโฟลเดอร์นี้

- `student/` สำหรับคู่มือนักศึกษา
- `teacher/` สำหรับคู่มืออาจารย์

กติกา:

- ไม่ถ่ายหน้า `/qa-login` ลงคู่มือผู้ใช้จริง
- ไม่เก็บ QA secret, token, หรือข้อมูลลับในภาพ
- ใช้ชื่อไฟล์ตามรายการใน `e2e-artifacts/manual-guide/MANUAL_CAPTURE_PLAN.md`
- ภาพควรมาจาก Classic/current production-like UI เท่านั้น
