## UTF-8 / mojibake note

- Thai manual files should be treated as UTF-8.
- PowerShell may display Thai text as mojibake even when the file itself is valid UTF-8.
- Before changing Thai text because it “looks broken” in terminal, verify in browser or with a UTF-8-aware reader.
- Do not write Thai docs with ad hoc shell redirection. Use `apply_patch` or an editor that preserves UTF-8.
