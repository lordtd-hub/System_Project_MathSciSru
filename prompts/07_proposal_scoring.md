# Task 07 — Proposal checklist scoring

Implement Proposal scoring for active internal teachers.

Rules:
- all active internal teachers can score
- checked item = points
- unchecked item = 0
- total calculated automatically
- critical item warning if unchecked
- decision required:
  - PASS
  - PASS_WITH_REVISION
  - NOT_PASS
- reason required for PASS_WITH_REVISION and NOT_PASS
- save draft and submit
- create timeline event on submit
